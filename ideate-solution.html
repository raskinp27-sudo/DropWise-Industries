Competitors / Existing Solutions

How today’s alternatives work—and where they leave packages exposed.

Ring Camera

Function: Records in real time the surroundings of a doorstep

Disadvantages: Expensive ($60–300) · Limited coverage with one camera · Does not actively prevent theft

Amazon Hub Locker

Function: Packages are delivered into a locker

Disadvantages: Size and weight limitations · Only available for apartments

Yale Smart Delivery Lock

Function: Secures packages by automatically locking after delivery

Disadvantages: Expensive ($280–330) · Deliverers are reluctant to use it · Size limitations · No sensors → can cause locking/security malfunctions

Potential Solutions

BarLock

Components: Barcode scanner · Solenoid · LCD screen

How it works: Barcode is mounted to the wall. Scanner reads package barcode → unlocks box temporarily. Deliverer places package inside. LCD provides instructions.

KeyLock

Components: Keypad · LCD screen · Solenoid

How it works: Box starts unlocked. Deliverer places package and enters code to lock it. Owner uses same code to unlock and retrieve package. LCD provides instructions.

ParcelGuard

Components: Solenoid · Weight sensor · Fingerprint sensor · LCD screen

How it works: Box remains unlocked when empty. Package is placed inside → weight sensor triggers automatic lock. Owner unlocks using fingerprint. Removing package resets system to unlocked state. LCD provides instructions.

Chosen Design

ParcelGuard is our final solution: a secure drop box that locks automatically when a package is detected, with fingerprint access for the owner—meeting our highest-weighted design goals without depending on carrier behavior.

Competitive Advantage

Why ParcelGuard stands apart from doorbell cameras, lockers, and smart locks.

  • Automatic locking via weight sensor — secures the package as soon as it is placed inside, without extra driver steps
  • No reliance on delivery driver behavior — unlike keypad or app-dependent flows carriers may skip or misuse
  • Secure fingerprint access — only the owner unlocks to retrieve; no shared codes left on packages
  • More reliable than competitors — physical enclosure plus detection beats record-only cameras and avoids locker size or apartment-only limits
