Abstract

Dropix is an autonomous package drop box that is secure against any attempts at stealing packages. Every year, millions of packages get stolen because of unsecured delivery points, costing Americans billions of dollars annually and preventing people from accessing necessary items, such as medicines, food, and office tools. Dropix solves this problem by acting as a protected container that delivery drivers place packages into, which automatically secures deliveries and prevents theft. The important components used to build Dropix include a fingerprint sensor to validate the owner, a weight sensor to detect packages, a solenoid to lock the chest, and an LCD to display instructions. The system is designed to be affordable, easy to use, and compatible with homes and apartments, ensuring packages remain safe from the moment they are delivered until the owner retrieves them.

The Solution

Dropix uses a protected drop box that secures itself the moment a package is placed inside — automatically, with no extra steps for the driver.

  • ✓ Protected container — Drivers place packages inside; no porch exposure.
  • ✓ Automatic securing — Locks when a package is detected; no manual action.
  • ✓ Prevents theft — Stops porch piracy instead of only recording it.
  • ✓ Affordable & easy — Designed for homes and apartments, simple to use.
